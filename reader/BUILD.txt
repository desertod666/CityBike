CURRENT ESP32 READER SOURCE: 0.6.8

The isolated GPIO loopback now configures GPIO5 as an input with no pulls,
checks the actual GPIO mux/enable bits and refuses before CTX LOW if setup
fails. The normal isolated selftest still holds LOW for only 100 us.

SELFTEST VOLTMETER ISOLATED is a separate correlated-USB-only command. The
owner must assert that bicycle CAN is physically disconnected. It adds one
fixed eight-second LOW window for a multimeter, with TWAI uninstalled. The
CAN owner yields and checks USB/STOP cancellation while waiting; both paths
restore GPIO4 HIGH before returning. No arbitrary timing or pin API exists.
It requires the isolated_gpio_voltmeter_v1 capability; Wi-Fi/RPC is denied.
No battery-service request, battery write or motor command is sent.

The portal build is 20261030-voltmeter1. Normal CAN timing, battery request
policy and BLE controls are unchanged. Prefer GitHub-hosted reader-ci with
pinned tools; verify native tests, ELF assets and partition size before use.
