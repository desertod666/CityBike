CURRENT ESP32 READER BUILD

Version 0.6.4 aligns the embedded portal with hosted build 20261029-battery1.
The main battery card reads current ESP CAN posts immediately. Full Information
and standard cell replies add detail when actually received; missing cells are
explicit, measured voltage stays separate from the cell sum, and old adapter
snapshots never replace current ESP readings. Local/remote USB and Wi-Fi share
the same display. Native CAN and BLE behavior is unchanged from verified 0.6.2.

Build only on the GitHub-hosted reader-ci workflow with pinned tools. Source
hashes, native tests, ELF assets and partition fit are checked before artifacts.
CI has no production credentials, USB access, server deploy or flashing step.
