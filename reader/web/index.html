      Штатный адаптер Spard
      Выберите штатный донгл (на прежних фото — COM4). Сайт отправит его USB VID/PID для определения. Определение получает только USB VID/PID. Для чтения используйте отдельную проверку ниже.
       
      Проверка общего трафика без запросов к батарее. Передача полных CAN ID этим адаптером пока не подтверждена.
      Перед проверкой освободите COM4 в Spard. Проверка настраивает адаптер на CAN 250 кбит/с и отправляет три штатных запроса Information. Настройки батареи не изменяются.
      Для выбора нужен Chrome или Edge. Результат определения появится в блоке батареи.

      Дополнительно: подключение и проводка
      Выбор профиля не запускает CAN.
      Схема M5.4/G5.4 из новых материалов
      Только для показанной пары HMI/BIKE PCB ↔ BIKE PCB/CU: GN (зелёный) — CAN-H; WT (белый) — CAN-L; BK (чёрный) — GND. BN — 36 В; OG — On/off. BN и OG к ридеру не подключаются. Сначала подтвердите соответствие вашего кабеля схеме; распиновка отдельного зелёного порта Control Box остаётся неизвестной.
      

      Для текущей линии PCB ↔ контроллер подтверждены 250 000 бит/с.
